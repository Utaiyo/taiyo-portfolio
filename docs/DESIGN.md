# Taiyo Uehara Portfolio — 設計ドキュメント

上原多一陽という人を「作品」として伝えるサイトの設計メモです。
実装は `src/` にあり、文章やデータはすべて `src/content/profile.ts` にまとめています。

---

## 1. コンセプト

**Anime × Editorial × Personal Portfolio — 「上原多一陽という連載」**

サイト全体を1本の連載マンガに見立てています。

- Hero は **EP.00 プロローグ**（タイトル画面）
- 各セクションは **EP.01〜07** の「話数」
- 最後は **次回予告（GA technologies 編）** → フッターの **TO BE CONTINUED…**

「まだ途中の物語」という見せ方にすることで、実績の羅列ではなく、いまも続いているストーリーとして伝えます。
アニメ・マンガの要素は、太い枠線・吹き出し・網点・集中線に絞りました。紙の色と雑誌のような余白で、子どもっぽくならないようにしています。

## 4. ビジュアルスタイル

- **線**：すべての枠を 3px の墨色にする。影はぼかさず、ずらしただけの「ハードシャドウ」にする
- **コマ**：白・紙・墨・黄の4種類の面を使い分けて、リズムをつくる
- **マンガ表現**：網点（ハーフトーン）、集中線、吹き出し、ナレーション枠、袋文字の話数
- **動き**：スクロールでふわっと出る／吹き出しはバネのようにポンと出る／Hero写真は軽い視差。「動きを減らす」設定の端末ではすべて止まる
- **雑誌の編集感**：Hero の上に「Issue No.001 / Vol.2026」のマストヘッドを置き、各セクションの見出しには雑誌のランニングヘッダー（EP.02 ──── 02 / 07）をつける
- **写真のレイヤー演出**：切り抜き写真の後ろに、同じ形の色シルエット（網点入り）をずらして重ね、版ズレした印刷物のような奥行きを出す（Hero は朱、Projects は黄。部品は `CutoutLayers.tsx`）
- **控えめにすること**：効果線は薄く（透明度 10〜16%）、本文の上には重ねない

## 8. 写真の使い方

| 写真 | 使う場所 | 加工 |
|---|---|---|
| A 夜の街 | HERO | 人物を切り抜き、白フチ16px＋墨線4pxのステッカー風にする。背景は同じ写真を強くぼかして夜景の玉ボケにし、コマの中に敷く。頭がコマの上からはみ出す配置にする |
| B マイク | PROJECTS | 同じく切り抜いてステッカー風にする。白いコマに集中線と朱の網点を入れ、スピーチ吹き出し2つと「ROLE / FIELD / STYLE」の注釈ラベルを添える |

- 書き出しは WebP（`public/images/`）。顔の色味やトリミングは元の写真のままにしています
- 写真を差し替えるときは、透過PNGかWebPを同じファイル名で置き、`profile.ts` の `width` / `height` を新しい画像のサイズに合わせてください
- 切り抜きのコツ：足元は画面の下で切れたままにして、白フチは上と左右だけにする（コマの下辺にぴったり乗るように）

## 9. 実装方針

- **Next.js 15（App Router）＋ TypeScript ＋ Tailwind CSS v4 ＋ Framer Motion**
- 構成
  ```
  src/
    app/            layout（フォント・メタ情報）, page（セクションの並び）, globals.css（色・効果）
    content/        profile.ts ← 文章・データはここだけ
    components/
      ui/           SpeechBubble, ChapterHeading, Reveal, NarrationBox（どこでも使い回せる部品）
      sections/     Hero, About, Story, WhatIDo, Projects, Beyond, NowNext, Contact
      Header, Footer
  public/images/    切り抜き写真・背景
  ```
- **更新のしかた**
  - プロジェクトの詳細：`projects` の各項目に `overview / background / role / ingenuity / learning` を書くと、カードに「＋詳しく」が自動で出ます。`comingSoon` を消すと「準備中」スタンプも消えます
  - 連絡先：`contact.links` の `href` にURL（メールは `mailto:...`）を入れると押せるようになります
  - 話を足す：`episodes` に1件足して、`Story.tsx` の `layout` にコマ幅を1行足します
- **アクセシビリティ**：見出しの階層、本文へのスキップリンク、フォーカス枠、画像の alt、装飾には `aria-hidden` をつけ、「動きを減らす」設定にも対応
- **軽さ**：ページは静的に書き出し、画像は WebP で合計約160KB。外部への通信はありません

## 10. 一筆書きサイン「Taiyo」

- Hero の写真の右下に、ブロマイドにサインを書くイメージで「Taiyo」を描きます
- 1本のパスで描いています。書き順は、T の横棒 → 縦棒 → a → i → y → o → 弧を描いて戻り、i の点で終わり
- パスは `src/content/signature.ts`、描画する部品は `src/components/ui/SignatureDraw.tsx`
- **スピード調整**：`src/content/profile.ts` の `signature` で変えます
  - `durationSec`：書き終わるまでの秒数（例：1.8 で速く、4 でゆっくり）
  - `delaySec`：ページを開いてから書き始めるまでの秒数
  - `strokeWidth`：線の太さ
  - `replayOnClick`：サインを押すと、もう一度書くかどうか
- サイト以外でも使える単体のSVG：`public/images/taiyo-signature.svg`（ブラウザで開くと描画されます。速さはファイル内の `--dur` で変えます）
